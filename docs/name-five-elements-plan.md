# 성명 한자 오행 분석 기능 계획

## 목적

성명의 한자를 입력하면 전통 성명학에서 사용하는 여러 오행 분류를 분리해 보여주고, 사주 원국의 오행 분포와 함께 참고용 해석을 제공한다.

이 기능은 과학적 사실이나 운명 판정이 아니라 전통 문화·오락용 해석으로 제공한다.

## 구분해야 하는 체계

- 자원오행: 한자의 뜻, 부수, 자형 등을 오행에 배속한다. 배속 기준은 유파별로 다를 수 있다.
- 음령오행: 한글 이름의 초성 또는 발음을 오행에 배속한다. 분류표 선택에 따라 결과가 달라질 수 있다.
- 수리오행: 한자 획수와 수리표를 이용한다. 원획·필기획 등 획수 기준이 다르면 결과도 달라진다.
- 삼원오행: 성과 이름의 획수 조합으로 천격·인격·지격 등을 계산하는 계열이다.
- 음양배열: 획수의 홀짝 배열을 본다.
- 사주 보완: 사주 원국에서 부족하거나 도움이 된다고 해석한 오행과 이름의 오행을 비교한다. 용신·희신 판단 자체도 유파와 계산 규칙에 따라 달라질 수 있다.

법적·행정적으로 확인 가능한 것은 대법원 인명용 한자 여부와 허용 음이다. 오행 배속과 획수 길흉은 공인 표준이 아니므로 결과 화면에 사용한 규칙 세트와 출처를 표시한다.

## 필수 데이터

- Unicode 코드 포인트와 이체자·동형이자 식별 정보
- 대법원 인명용 한자 여부, 허용 음, 시행 버전
- 한자의 음과 훈, 부수, 자형 정보
- 획수 값과 획수 기준·사전·버전
- 자원오행 값과 유파·근거·출처
- 음령오행 분류표와 버전
- 수리·삼원 계산 규칙 세트와 버전
- 데이터 출처 URL, 확인일, 갱신일, 신뢰도

단일 `total_strokes`나 `element_hint` 필드로 합치지 않는다. 한 문자에 여러 유파의 해석을 별도 레코드로 저장한다.

## 개인정보 원칙

- 실명, 생년월일, 출생시각은 기본적으로 브라우저 내부에서만 처리한다.
- 서버 저장은 기본 비활성화하고 사용자가 명시적으로 저장할 때만 최소 정보를 보관한다.
- 공유·복사 화면에는 실명 숨김 옵션을 제공한다.
- 미성년자 이름 데이터와 가족관계 정보는 수집하지 않는다.

## 단계별 개발

1. 인명용 한자 검색과 법적 사용 가능 여부 표시
2. 한자별 음·훈·부수·획수·출처 표시
3. 유파를 선택할 수 있는 자원오행·음령오행 분석
4. 획수 기준을 명시한 수리·삼원·음양 배열 계산
5. 사주 원국 오행과 비교하는 참고용 보완 분석
6. 기준 사례 회귀 테스트와 전문가 교차 검토

## UI 원칙

- 한글 이름을 입력하면 가능한 한자 후보를 선택하게 한다.
- 결과를 `법적 사용 가능`, `문자 정보`, `전통 해석`, `사주 비교`로 분리한다.
- 각 결과에 사용 규칙, 출처, 버전, 불확실성을 표시한다.
- “좋은 이름/나쁜 이름” 단정 대신 유파별 해석 차이를 비교한다.

# 사주/궁합/작명 전체 데이터 커버리지

## 1. 정정

기존 문서에서는 사주팔자 MVP를 빠르게 만들기 위해 천간, 지지, 오행, 십성, 합충, 역법, 작명 데이터를 먼저 잡고, 대운/세운/계절 비유/관운/재물운 같은 고급 풀이 데이터를 뒤로 미뤘다.

하지만 사용자가 기대하는 "실제 사주풀이를 보러 갔을 때 듣는 수준"의 결과를 만들려면 아래 데이터는 확장 기능이 아니라 핵심 데이터다.

- 대운
- 세운
- 월운
- 십성 분포
- 지장간 십성
- 격국
- 용신/희신/기신 후보
- 계절감/월령 해석
- 관운
- 재물운
- 이직/직장운
- 사업운
- 배우자운
- 자식운
- 건강/컨디션 운
- 삼재
- 신살
- 나이대별 전환기
- 작명용 오행/한자/음절 데이터

따라서 DB 기준은 `db/schema.sql`로 통합한다.

## 2. 왜 누락되면 안 되는가

짧은 오늘 운세나 단순 성향 분석은 오행 분포와 간단한 해석 seed만으로도 만들 수 있다. 하지만 아래 표현은 더 깊은 계산과 해석 데이터가 있어야 한다.

- "겨울에 핀 코스모스 같은 사주"
- "관운이 약하다"
- "조직보다 자율성이 맞다"
- "28세 전후 이직 기회가 있다"
- "42~43세부터 재물운이 풀린다"
- "이때 만나는 직장/거래처는 오래 갈 수 있다"

이런 문장은 단순 문장 생성이 아니라 다음 데이터의 조합으로 만들어야 한다.

- 출생 월의 계절성
- 일간과 월령의 관계
- 오행의 한난조습
- 십성의 강약
- 대운에서 들어오는 천간/지지
- 세운에서 들어오는 천간/지지
- 원국과 대운/세운의 합충형파해
- 관성/재성/식상/인성/비겁의 활성화 시점

## 4. 구현 기준

AI가 임의로 "28세에 이직운" 같은 말을 만들면 안 된다. 아래 순서로 만들어야 한다.

1. 생년월일시를 역법 데이터로 정규화한다.
2. 사주 원국을 계산한다.
3. 십성, 지장간, 오행 강약을 계산한다.
4. 대운 시작 나이와 방향을 계산한다.
5. 대운/세운을 계산한다.
6. 관성, 재성, 식상 등 주요 십성이 언제 강해지는지 찾는다.
7. 합충형파해로 변화 압력이 큰 나이대를 찾는다.
8. DB의 `advanced_saju_rules`, `luck_domain_rules`, `season_metaphor_rules`에서 해석 seed를 조회한다.
9. AI는 계산 결과와 seed를 바탕으로 장문 풀이를 문장화한다.

## 5. 출생 시간 모름 처리

출생 시간이 없으면 아래 항목의 신뢰도를 낮춘다.

- 시주
- 자식운
- 말년운
- 세부 건강/컨디션 패턴
- 대운 시작점의 정밀도
- 특정 나이의 세밀한 사건성

그래도 아래 항목은 어느 정도 풀이할 수 있다.

- 연주
- 월주
- 일주
- 계절감
- 기본 오행 흐름
- 기본 십성 흐름
- 대략적 대운/세운 경향
- 삼재

## 6. DB 기준 파일

전체 DB 스키마는 아래 파일을 기준으로 한다.

```txt
db/schema.sql
```

이 파일은 Supabase/PostgreSQL에 올릴 수 있는 기준 스키마다.
